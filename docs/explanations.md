# Объяснения по lean-fns

Использовать [ce-explain](../.agents/skills/ce-explain/SKILL.md), чтобы объяснять поведение API, сборку пакета, конкретное изменение или историю работы над проектом. Обосновывать выводы по исходникам, тестам, конфигурации и истории Git. Отделять подтверждённое поведение и документированные решения от предположений.

- Для вопроса о поведении проследить вызов до результата по коду и тестам. Для сборки ESM/CJS сверить `package.json`, конфигурацию tsdown и проверки потребителей.
- Для изменения использовать указанный коммит, PR или диапазон `diff:<BASE>..<HEAD>`. Для истории использовать заданный период или `since:<ref>`.
- Маршрутизацию и запуск помощников определять по [авторским правилам](../.agents/skills/ce-explain/references/orchestration.md). Основной Codex составляет объяснение на основе проверенных источников.

Для ответа в чате использовать ссылки на источники. Если запрошен отдельный Markdown-файл, использовать `output:md` и сохранить его по заданному пользователем пути в Obsidian согласно [правилам проекта](../AGENTS.md#хранение-контекста). Публикация требует отдельного поручения.
